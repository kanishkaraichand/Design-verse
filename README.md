

DesignVerse is a responsive landing page for a fictional one-day fest organised by Nirvana Design Society, IGDTUW, on 22 October 2026 at the Auditorium, IGDTUW, from 11:00 AM onwards. It is open to first-year students. The page introduces the event, shows the key details (date, time, venue), and highlights the activities: Design Challenge, Innovation Sprint, Workshops, Design Exhibition and Guest Talks. It also includes an interactive schedule and a registration form that encourage students to sign up. The design uses a dark theme with pink, violet and blue accents to give the event a futuristic, creative identity.

## Technologies Used
HTML, CSS, JavaScript, GSAP (ScrollTrigger), Lenis smooth scroll, Google Fonts (Syne and Inter). Designed with Google Stitch and Figma. Hosted on Vercel.

## Features
- Sticky navbar with mobile hamburger menu and smooth scrolling
- Moving tagline marquee
- Event details cards, About section with animated stats
- Highlights cards with hover effects
- Interactive schedule with filter tabs
- Registration form with validation and submission
- Fully responsive for mobile, tablet and desktop
